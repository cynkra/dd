# DuckDB function ST_SimplifyPreserveTopology

Returns a simplified version of the geometry that preserves topology.

## Usage

``` r
ST_SimplifyPreserveTopology(geom, tolerance)
```

## Arguments

- geom:

  `GEOMETRY`

- tolerance:

  `DOUBLE`

## Value

`GEOMETRY`

## Provided by

The `spatial` extension (`LOAD spatial;`).
