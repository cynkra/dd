# DuckDB function html_escape

DuckDB function `html_escape()`.

## Usage

``` r
html_escape(col0, col1)
```

## Arguments

- col0:

  `VARCHAR`

- col1:

  `BOOLEAN`

## Value

`VARCHAR`

## Overloads

- `html_escape(col0 = VARCHAR)`

- `html_escape(col0 = VARCHAR, col1 = BOOLEAN)`

## Provided by

The `inet` extension (`LOAD inet;`).
