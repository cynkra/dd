# DuckDB function json_serialize_sql

DuckDB function `json_serialize_sql()`.

## Usage

``` r
json_serialize_sql(col0, col1, col2, col3, col4)
```

## Arguments

- col0:

  `VARCHAR`

- col1:

  `BOOLEAN`

- col2:

  `BOOLEAN`

- col3:

  `BOOLEAN`

- col4:

  `BOOLEAN`

## Value

`JSON`

## Overloads

- `json_serialize_sql(col0 = VARCHAR)`

- `json_serialize_sql(col0 = VARCHAR, col1 = BOOLEAN)`

- `json_serialize_sql(col0 = VARCHAR, col1 = BOOLEAN, col2 = BOOLEAN)`

- `json_serialize_sql(col0 = VARCHAR, col1 = BOOLEAN, col2 = BOOLEAN, col3 = BOOLEAN)`

- `json_serialize_sql(col0 = VARCHAR, col1 = BOOLEAN, col2 = BOOLEAN, col3 = BOOLEAN, col4 = BOOLEAN)`

## Provided by

The `json` extension (`LOAD json;`).
